# Tally 설문과 응답 관리 절차

## 연결 정보

- 공개 설문: `https://tally.so/r/ZjAlQe`
- 응답 시트: `https://docs.google.com/spreadsheets/d/1RL9klWR9-vHfFmb4GMGPUEnuO0GLpbW_C-4IekWTtQQ/edit`

## 설문 변경 점검

1. 편집 화면이 아니라 공개 링크에서 동작을 확인한다.
2. 한국어, 일본어, 영어를 각각 선택해 해당 질문만 보이는지 확인한다.
3. 언어 선택 후 빈 화면이 생기지 않는지 확인한다.
4. 연락 방법은 현재 운영 정책과 일치하는지 확인한다.
5. 웨이팅 등록 지원, 방문일, 지역, 예산, 인원, 식이 제한, 연락처가 포함되는지 확인한다.
6. 변경 후 Tally 게시 상태를 확인한다.

## 응답 시트 관리

- `시트1`은 Tally 원본이므로 삭제, 열 재배치, 이름 변경을 하지 않는다.
- 운영자는 `운영 관리` 탭을 사용한다.
- 진행 상태는 `신규 접수`, `결제 안내`, `결제 완료`, `큐레이션 중`, `전달 완료`, `취소` 중 하나를 선택한다.
- 개인정보가 포함될 수 있으므로 시트 공유 범위를 불필요하게 넓히지 않는다.

## 변경 후 검증

1. 테스트 응답이 필요한 경우 실제 제출 전에 테스트 데이터와 전달 대상을 확인한다.
2. 제출 시 원본 탭에 새 행이 생기는지 확인한다.
3. `운영 관리` 탭에 핵심 필드가 자동 표시되는지 확인한다.
4. 한국어 상세 응답 열이 누락되어 있으면 Tally의 Google Sheets 연동을 갱신하거나 다시 연결한 뒤 재검증한다.
5. 랜딩 페이지 CTA가 공개 Tally 링크를 사용하는지 확인한다.
