## 홍보 문구 초안

### 카카오톡

서울 맛집을 검색하다 광고성 목록에 지치셨다면 Deep Plate를 한번 써보세요. 일정·취향·예산을 알려주시면 직접 확인한 로컬 식당을 1:1로 골라드립니다. 지금은 서비스 흐름을 검증하는 테스트 단계이며 실제 결제는 발생하지 않습니다.

### 네이버 블로그

서울 맛집 정보는 많지만, 내 일정과 취향에 맞는 한 끼를 고르는 일은 여전히 어렵습니다. Deep Plate는 광고 목록을 늘리는 대신 여행 일정·예산·알레르기와 원하는 분위기를 확인하고 사람이 직접 식당을 골라주는 1:1 큐레이션을 실험하고 있습니다. 신청부터 테스트 결제까지 사용해보고 불편한 점을 알려주세요.

### 인스타그램

두 번째 서울 여행이라면, 이번에는 관광객 목록 말고 내 취향에 맞는 한 끼.
Deep Plate 1:1 로컬 다이닝 큐레이션을 테스트해보세요.
광고 없이 직접 확인한 정보로 고릅니다.

## 운영 규칙

- 실제 게시 전 각 채널에서 링크가 클릭 가능한지 확인한다.
- 링크 단축기를 쓰더라도 최종 도착 URL의 UTM이 유지되는지 확인한다.
- 소재를 수정하면 기존 `utm_content`를 덮어쓰지 않고 `v2`를 새로 만든다.
- 내부 테스트는 홍보 링크를 쓰지 않고 `utm_campaign=mission9_qa`를 사용한다.
- 게시 날짜, 게시 위치, 소재 버전, 조회·클릭 증빙을 아래 기록표에 남긴다.
