# Deep Plate 마스터 브리프

버전: v2.1 현재 운영 기준
마지막 갱신: 2026-08-06

이 문서는 코드와 운영 도구에서 확인된 현재 상태를 기준으로 한다. 항목은 `확정`, `실험 중`, `미정`으로 구분하며, 미정 사항을 외부에 확정적으로 표현하지 않는다.

## 1. 사업과 고객

- 상태: 확정
- Deep Plate는 여행자의 일정, 취향, 예산, 식이 조건을 바탕으로 창업자가 직접 로컬 다이닝을 선정하는 1:1 수작업 큐레이션 서비스다.
- 현재는 1인 창업자가 유료 수요와 운영 가능성을 검증하는 린 MVP 단계다.
- 핵심 고객은 한국을 재방문하며 광고성 추천보다 서울의 로컬 식문화를 찾는 일본인 여행자다.
- 한국어, 일본어, 영어로 같은 신청 흐름을 제공한다.

## 2. 브랜드 원칙

### 확정

- 서비스명: Deep Plate / 딥 플레이트
- 기반 지역: 서울
- 핵심 가치: 광고 노출이 아닌 직접 방문과 여행자 적합성을 기준으로 선정한다.
- 톤: 담백하고 신뢰감 있는 고급 미식 매거진의 편집 디자인
- 메인 색상: 크림 `#FBF9F5`, 텍스트 `#111111`, 포인트 레드 `#B81D24`
- 심볼은 현재 SVG 벡터를 유지하고 워드마크에는 `DEEP PLATE`와 `딥 플레이트`를 함께 사용한다.

### 사용하지 않는 표현

- 100% 인증, GPS·EXIF 자동 인증, 인증 데이터베이스
- 전담 큐레이터팀처럼 실제보다 큰 조직을 암시하는 표현
- 도쿄 지사 또는 서울 이외의 운영 거점
- 확정되지 않은 순위, 리스트, 가격, 결제 수단
- 자동 웨이팅 등록 또는 자동 대행
- 정식 결정되지 않은 `Culinary Archive` 서브브랜드

## 3. 현재 고객 여정

1. 고객이 랜딩 페이지에서 Tally 공개 설문을 연다.
2. 일정, 지역, 취향, 예산, 알레르기·식이 조건과 원하는 연락 방법을 제출한다.
3. 응답은 Google Sheets 원본 탭에 저장되고 운영용 탭에서 진행 상태를 관리한다.
4. 운영자가 고객이 선택한 연락 방법으로 현재 이용 가능한 결제 수단을 안내한다.
5. 결제 확인 후 직접 큐레이션한다.
6. 1~2일 안에 Google Maps 링크가 포함된 맞춤 결과물을 전달한다.

### 결과물

- 상태: 실험 중
- 외부 문구는 형식이 확정될 때까지 `맞춤 리포트` 또는 `맞춤 결과물`로 표현한다.
- PDF 템플릿 제작과 실제 전달 방식이 검증된 뒤에만 `PDF 리포트`로 확정한다.

### 가격과 결제

- 상태: 실험 중
- 가격은 소규모 지불 의사 검증 단계이며 고정 가격으로 홍보하지 않는다.
- 표본 10명의 가격 비교는 방향성을 확인하는 정성적 실험으로 취급하며 통계적으로 확정된 A/B 테스트라고 표현하지 않는다.
- PayPal, Stripe 등 결제 수단은 실제 사용 가능 여부를 확인한 뒤 공개한다.

## 4. 설문과 응답 관리

- 공개 설문: `https://tally.so/r/ZjAlQe`
- 설문 도구: Tally
- 원본 응답: Google Sheets `시트1`
- 운영 관리: Google Sheets `운영 관리`
- 원본 탭은 삭제하거나 이름과 열 구조를 임의로 변경하지 않는다.
- 한국어 상세 응답 열은 Tally 연동 상태를 다시 확인해야 한다.

## 5. 연락 채널

- 상태: 일부 미정
- 신청 단계에서는 Tally에서 고객이 선택한 연락 방법을 사용한다.
- 웹사이트 푸터에는 실제 주소와 작동 여부가 확인된 채널만 링크한다.
- Instagram 계정의 정확한 공개 URL이 확인되기 전에는 링크를 노출하지 않는다.
- `hello@deepplate.co`, LINE, X는 현재 공식 운영 채널로 확정하지 않는다.

## 6. 웨이팅 도움

- 상태: 확정
- 자동 등록이나 실시간 대행 기능이 아니다.
- 한국 전화번호가 없어 등록이 어려운 고객에게 가능한 범위에서 수동으로 개별 안내한다.
- 특정 서비스의 약관 준수 여부와 개인정보 처리 방식은 실제 운영 흐름을 확정할 때 별도로 검토한다.
- 고객 정보를 받을 때는 수집 목적, 항목, 보유 기간, 거부 권리 등 필요한 고지를 마련한다.

## 7. 랜딩 페이지 구조

- React 19와 Vite 8 기반 단일 페이지 애플리케이션이다.
- 주요 흐름은 Header, Hero, Problem & Solution, Curation Archive, How It Works, FAQ, Footer로 구성한다.
- 섹션 수를 네 개로 강제하지 않고 고객이 신청을 결정하는 데 필요한 정보만 유지한다.
- 모든 CTA는 동일한 Tally 공개 설문을 연다.
- 한국어, 일본어, 영어 전환 시 빈 화면, 줄바꿈, CTA 링크를 확인한다.
- 모바일과 데스크톱에서 충분한 여백, 선명한 이미지, 읽을 수 있는 글자 크기를 유지한다.
- 장식적인 바운스 애니메이션과 무거운 그림자는 사용하지 않는다.

## 8. 콘텐츠 원칙

- 직접 확인한 사실과 앞으로의 계획을 구분한다.
- `저희`는 브랜드 화법으로 사용할 수 있지만 실제 팀 규모를 암시하지 않는다.
- 추천 순위를 판매하지 않는다는 원칙을 유지한다.
- 카드의 `DIRECT VERIFICATION`은 사람이 직접 방문해 확인한다는 의미로만 사용한다.
- 아직 제작되지 않은 콘텐츠에는 `COMING SOON`을 붙인다.

## 9. 시장 자료 사용 기준

- 시장 수치는 조사 연도, 지표 정의, 출처 URL을 함께 적은 경우에만 외부 자료에 사용한다.
- `방한 재방문율 56.6%`는 공식 원문을 확인하기 전까지 사용하지 않는다.
- 캐치테이블 글로벌 앱 MAU 112만 5,188명과 일본 이용자 비중 29.63%는 2026년 5월 기준 보도 수치이므로 시점을 생략하지 않는다.
- 망고플레이트의 서비스 종료 사실과 종료 원인에 대한 해석을 구분한다. 광고 도입이 실패 원인이라는 문장은 근거 없이 사용하지 않는다.

## 10. 조직 원칙

- 현재는 창업자 1인 운영이다.
- 공동창업자나 팀원은 역할을 채우기 위해 급히 정하지 않고 실제 협업으로 적합성과 기여도를 확인한다.
- 향후 조직 구조와 지분 조건은 계획이며 현재 팀 구성처럼 표현하지 않는다.
